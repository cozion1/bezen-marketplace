# BEZEN MCP — קריאת תשובות בכמות

מחבר MCP שמקבל **עד 25 תשובות של לידים בקריאה אחת** ומחזיר לכל אחת את הקריאה של BEZEN: על מה האדם מגן, מה אסור לעשות עכשיו, ו-`send: auto | human | none`.

רץ על מודל זול, כדי שסוכן לא ישרוף טוקנים על כל תשובה בנפרד.

## למי זה

מי שמריץ סוכן מכירות שממיין תשובות — גרוק בוט, Zapier, Make, n8n, או סוכן משלו — ומעביר הרבה תשובות ביום. אם אתה קורא תשובה-תשובה ביד, אתה לא צריך את זה; תתקין את `bezen-replies` והוא עושה את אותה קריאה בחינם, מקומית, בלי מפתח.

## התקנה

```
/plugin marketplace add cozion1/bezen-marketplace
/plugin install bezen-mcp@bezen
```

ואז מגדירים את המפתח כמשתנה סביבה:

```
BEZEN_KEY=<המפתח שקיבלת>
```

**המחבר לא עובד בלי מפתח אישי.** יש מכסה יומית לכל מפתח, כי כל קריאה עולה כסף אמיתי. לבקשת מפתח ניסיון — דרך הדף: https://bezen-63b2ea.netlify.app/plugins

## הכלי

`read_replies` — מקבל `replies`: רשימה של `{"id": "...", "text": "..."}`, עד 25 בקריאה.
מחזיר לכל אחת את אותו מבנה שמחזיר הסקיל `bezen-replies`.

## מה זה לא

המחבר משנה **איך** עונים, לא **מה** מציעים. מחיר, הנחה, דמו או פגישה נלקחים רק מההנחיות של העסק שלך.
